Weather
Возможности
- Отображение текущей температуры и описания погодных условий.
- Влажность, количество осадков и скорость ветра.
- Прогноз максимальной температуры на ближайшие 4 дня.
- Поиск погоды по названию города.
- Начальный город — Бишкек.
Как запустить
Зайти на мой дескрипшн и открыть сайт через мой гитхаб pages
Технологии
- HTML5
- CSS3 (Grid, Flexbox, Media Queries)
- JavaScript (Fetch API, async/await)
- Open-Meteo API
Примечания
- Для загрузки погоды и поиска города требуется подключение к интернету.
- Фотография фона и шрифт загружаются с внешних сервисов.
- Если API временно недоступен, на странице появится сообщение об ошибке.
- Скорость ветра отображается в км/ч, температура — в °C.
Источники
- Open-Meteo — Forecast API
- Open-Meteo — Geocoding API
